# PMC Calling Bot — Latency & TTS Cost Work Report (13 Oct 2026)

## Summary

The code for measuring and cutting call latency and TTS cost is built, tested offline and running on branch `test/latency`. The before/after test calls that prove the savings have not been made yet. Nothing is committed.

- **Goal:** find out how long callers wait between finishing a sentence and hearing the bot, and cut that wait and the TTS bill. TTS is the biggest running cost: ₹0.97 of ₹2.09 per minute (46%).
- **Where it stands:** per-call latency and TTS-cost logging is in place, the greeting and "please wait" lines are pre-recorded, the script is shorter, and the LLM now runs on Sarvam 105B Conversations. The server boots cleanly with all Sarvam keys working.
- **What blocks the next step:**
    1. No baseline or after test calls have been made, so there are no real numbers yet.
    2. Test calls would file real complaints into the PMC CMS unless `CMS_API_KEY` is blanked for the tests.
    3. The large prompt cut (43.5k characters) is deferred, because it needs the full set of live behaviour tests run around it.

## What was built and changed

Fourteen files were changed (+227 / −27 lines) and five added on `test/latency`, all uncommitted.

|   |   |   |
|---|---|---|
|Change|What it does|Files|
|Per-call latency and cost log|For every turn, records the caller's turn-end wait, STT, LLM and TTS first-byte times, and total voice-to-voice wait. For every call, adds TTS characters (the Sarvam bill), LLM tokens and CMS/geocoding time. Writes one JSON line per call. Built on pipecat's own `UserBotLatencyObserver`.|`server/latency.py`, `server/bot.py`|
|Report script|Compares batches of calls tagged with `LATENCY_LABEL` (e.g. baseline vs after): p50/p95 per stage, plus ₹ and tokens per call.|`scripts/latency_report.py`|
|Pre-recorded fixed lines|The greeting and the three "please wait" lines are recorded once per voice and sample rate, then played from disk: no TTS charge and no TTS wait for them. Falls back to live TTS when a recording is missing.|`server/audio_cache.py`, `server/bot.py`, `server/tools.py`, `server/app.py`|
|Gender-correct "please wait" line|Built from `AGENT_GENDER`, like the greeting. It was hard-coded masculine.|`server/tools.py`, `server/prompts.py`|
