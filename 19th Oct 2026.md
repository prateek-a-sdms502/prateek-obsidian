## 5. Built the cost model (`cost_model/`)
- **One set of formulas drives everything:** each formula is written once and turned into Python, Excel and JavaScript, so all three always give the same answer.
- **What it models:**
  - **Speed and capacity:** how many users each server can serve at the chosen speed.
  - **Memory:** how much context memory 90 users need, and how auto-summarization saves memory.
  - **Rent:** rental cost.
  - **Buy:** customs, building the room, power, cooling, staff, financing at 11%, and resale value.
  - **Colocation:** server cost plus colocation fees.
- **Main files:**
  - `catalog.py`: all the formulas.
  - `engine.py`: runs every combination (39,600 rows).
  - `build_xlsx.py`: builds the Excel workbook.
  - `build_js.py`: builds the web calculator's code.
  - `calibrate.py`: fits the model to the published benchmarks.
  - `parity.py`: checks that Python, Excel and JavaScript agree.
  - `make_summary.py`: writes the results tables.

- **Cause:** GLM-5.3 at FP8 on H200, with 90 coding-agent users, was given **10 servers**. The model always put each copy of a model on the fewest servers that could hold it, even when that left too little room for users. That meant adding copy after copy.
- **Fix:** the model now also tries spreading one copy across two or three servers, and picks whichever layout needs the fewest servers in total.
